## Tips
- Keep images roughly **4:3** (e.g. 800×600px) so they crop nicely in the cards.
- Use `.jpg` files with the exact names above (or update the `img:` path in
  `script.js` if you rename anything).
- Do not use copyrighted photos from Pizza Hut's website without permission —
  use your own photography or a licensed/stock image instead.
- `favicon/favicon.png` is also a placeholder icon — swap it for your own if desired.
